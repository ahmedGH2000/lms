# Project guidance for Codex

## Workflow

- Inspect only files relevant to the current task.
- Preserve existing business logic and API contracts.
- Make focused changes without unrelated refactoring.
- Reuse existing components and dependencies.
- Ask before adding production dependencies.

## Frontend

- Follow the existing framework and coding style.
- Improve accessibility and responsive behavior.
- Keep UI consistent with the application's design system.
- Verify Arabic RTL and English LTR behavior.
- Test mobile and desktop layouts when changing UI.

## Safety

- Never delete production data or database volumes.
- Preserve environment files, credentials, and uploads.
- Review existing changes before editing related files.

## Verification

- Run relevant build, lint, and tests after changes.
- Report changed files, test results, and remaining issues.
- Keep the final summary concise.
